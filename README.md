# 余烬 · 荒野手记

一款原始河谷题材的俯视角生存小游戏。**本机双击「开始游戏.bat」即可试玩**，也可用 Godot 打开工程后按 **F5**。推荐 Godot 4.3 或更高版本；本机使用 Godot 4.7.2 验证。无需安装插件、下载图片或联网。

从第一天早上 08:00 开始，在河谷中生存完整的 **72 小时**。白天收集物资，在高地营地制作石器、营火与枝叶庇护所，备好饮水和食物，夜晚守住火光。通关后可以继续自由生存。

## 操作

| 操作 | 按键 |
|---|---|
| 移动 | WASD、方向键，或点击地面 |
| 就近采集 / 交互 | E，或屏幕下方交互按钮 |
| 制作面板 | B |
| 营地添柴、休息、睡觉 | Q，或右侧「营地」 |
| 食用浆果 / 饮用净水 / 使用火把 / 食用熟食 | 1 / 2 / 3 / 4，支持数字小键盘 |
| 应对附近的狼 | F，或预警中的驱赶按钮 |
| 生存手记 | J |
| 操作帮助 | F1 |
| 暂停 / 关闭手记 | Esc |

右上角可以静音、暂停和打开帮助。读手记、查看帮助、切到其他窗口时会暂停。

食物也可以直接点击屏幕底部快捷栏使用，或打开右侧「背包」，点击浆果、净水、烤野薯所在行的「食用 / 饮用」。

## 第一晚建议

1. 营地左下是木材，右下是石块。靠近资源出现名称提示后按 E；每份资源可以采集三次。
2. 收集木材 4、石块 3，回到营地制作营火。初始营火有 12 小时燃料，每次添加 2 木材可再烧 10 小时。
3. 再收集木材 6、纤维 5，搭建庇护所。石斧能提升后续采木效率。
4. 去东侧河岸取生水，在营火旁用生水 1、木材 1 煮出净水。浆果可吃，野薯需烤熟。
5. 第一天下午 18:00 出现狼嚎预警。150 游戏分钟内，回到燃烧的营火旁按 F，或使用火把驱赶。石矛可防御，但仍可能擦伤。
6. 第二天 10:00 会预告中午降雨。提前加固棚顶、储备燃料，雨天靠近棚子以减少失温。

游戏时间每现实秒推进约 1.6 分钟；采集、制作和休息会额外推进时间。休息同样消耗食物、饮水和燃料，狼嚎会打断睡眠。资源耗尽后 24 游戏小时再生。

## 包含的玩法

- 连续行走、点击地面移动、资源高亮、角色遮挡、河岸边界。
- 生命、饱食、饮水、体力、保暖五项生存状态。
- 木材、石块、纤维、浆果、生水、净水、草药、野薯与熟食。
- 营火、庇护所、棚顶加固、石斧、石矛、火把、煮水、烹饪、敷料。
- 昼夜变化、动态营火、降雨、野狼预警与应对。
- 八篇生存手记与旅程记录。手记明确区分游戏简化规则和现实常识。
- 原创程序绘制场景和合成音效、环境鸟鸣。
- 自动本地存档、继续旅程、重开确认、胜利与失败结算。

## 存档

自动存档在采集、制作等操作后及游戏进行时每 20 秒更新。右侧营地也可手动保存。存档使用 Godot 的 `user://ember_save.json`，默认在 Windows 的 `%APPDATA%/Godot/app_userdata/余烬 · 荒野手记/`。新旅程只覆盖本游戏的存档。损坏或版本不兼容的存档会显示提示，不会直接加载。

## 项目结构

- `scripts/game.gd`：资源、制作、时间、危险、存档与游戏进程。
- `scripts/world.gd`：原创程序绘制的河谷、树木、营地、角色、天气。
- `scripts/hud.gd`：可鼠标 / 键盘操作的界面、帮助和手记。
- `scripts/sound.gd`：本地合成的环境音和交互提示音。
- `tests/test_survival.gd`：核心生存流程及回归验证。

中文使用系统字体（优先微软雅黑，再回退至 Noto Sans CJK）。其他系统需要安装中文字体。当前是可玩的 2D 原型，河流构成地图东侧边界；没有联网、复杂寻路或真实物理战斗。

命令行测试：`Godot --headless --path . --script tests/test_survival.gd -- --test`

完整三天生存流程与鼠标界面测试：`Godot --headless --path . --script tests/test_playthrough.gd -- --test`。该测试只使用初始物资和实际采集、制作、行走、休息消耗，不向背包注入额外资源；结果保存在 `artifacts/playthrough.txt`。
